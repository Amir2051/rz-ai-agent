Slack CLI · local developer workflow
CREATE AND RUN A SLACK APP
Run these commands in a trusted local terminal (for example, your Kali machine). The CLI authentication is interactive; MIA does not need your Slack password or tokens.
  1. Check the CLI
    ./scripts/slack-cli-workflow.sh check
    If missing, use the guided installer below or follow Slack’s official install instructions.
  2. Install (only if needed)
    ./scripts/slack-cli-workflow.sh install
    The helper downloads the official installer over HTTPS to a temporary file and asks before running it.
  3. Authenticate to your workspace
    ./scripts/slack-cli-workflow.sh login
    Complete the Slack authorization flow in the browser/terminal.
  4. Create a starter project
    ./scripts/slack-cli-workflow.sh create
    Follow the Slack CLI prompts and choose a project name/template.
  5. Run the project locally
    cd <your-new-slack-project>
slack run
    Keep the terminal open; stop with Ctrl+C. You can also call the helper by its full path: /path/to/rz-ai-agent/scripts/slack-cli-workflow.sh run.
Security: never paste Slack tokens, signing secrets, client secrets, or passwords into MIA chat. Do not commit .env or credential files. Review OAuth scopes and generated manifest before installing the app in a workspace. slack run runs locally; it does not deploy to production.

Safety
CONNECTION BOUNDARIES
Use least-privilege provider permissions. Never put secrets in a URL or paste them into chat. A saved endpoint is not a successful connection: RZ marks it connected only after tool discovery succeeds. Provider write tools must still pass the Tool Center approval flow.
